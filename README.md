FitChat – Fitness Chat with WebSocket

![FitChat Screenshot](screenshot.png)

Real-time chat with calorie, water, and step tracking. Built with Node.js + Socket.io using the Observer pattern.

Features

-  Real-time messaging (WebSocket)
-  Track calories, water intake, steps
-  Change nickname in chat
-  Emojis and health tips

 Tech Stack

- Node.js + Express
- Socket.io (WebSocket)
- HTML, CSS, JavaScript
- Observer Pattern

How to Run

```bash
git clone https://github.com/Sabinochkaaa/FitChat-Observer.git
cd FitChat-Observer
npm install
npm start
